Two functions decide whether an agent may act

The model asks to write a file or run a command. decideWrite and decideShell answer with one of three outcomes. Both are pure, both live in src/workbench/authority.ts, and the order of their checks is the security property.

1 · escape

Does the path leave the workspace?

2 · protected evidence

Does a pattern cover the target?

3 · strictest wins

Each concern votes; the worst carries.

4 · the grant

The axis grant supplies the answer.
