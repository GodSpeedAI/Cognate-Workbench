Done has seven levels, and they do not skip

An agent that says "I fixed it" can move the first level, maybe the second. It cannot reach ready-for-review, and it can never reach accepted. The function that enforces this is doneLevel, and its rule is contiguity.

Set the inputs

The five flags below are exactly what doneLevel takes. Turn on a later flag while an earlier one is off to see contiguity refuse it.
